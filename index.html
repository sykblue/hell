2019년 11월 출시

맥북 프로 16인치 (2019)

추천

인텔 칩을 쓴 마지막 16인치 맥북 프로예요. 큰 화면과 좋은 스피커, 다시 돌아온 시저 키보드 덕분에 문서 작업과 가벼운 개발에는 아직 충분해요.

칩
인텔 9세대 Core i7(6코어) 또는 i9(8코어)
화면
16인치 Retina, 3072×1920
그래픽
AMD Radeon Pro 5300M / 5500M
메모리
16GB ~ 64GB
단자
Thunderbolt 3 4개, 3.5mm 이어폰
무게
약 2.0kg

아직 좋은 점

  • 실제 Esc 키가 있는 시저 키보드라 타자감이 안정적이에요.
  • 16인치 화면과 6개 스피커는 지금 기준으로도 좋은 편이에요.
  • Windows를 Boot Camp로 직접 설치할 수 있어요. 인텔 맥만 가능한 일이에요.

알아 둘 점

  • 애플은 macOS Tahoe(26)를 인텔 맥이 받는 마지막 macOS라고 밝혔어요. 그 뒤로는 보안 업데이트만 한동안 받아요.
  • 무거운 작업을 하면 팬 소리가 크고 뜨거워져요. 배터리도 빨리 줄어요.
  • Apple 실리콘 전용 앱은 쓸 수 없어요.

중고로 살 때 확인할 것

  • 배터리 사이클 수와 상태 (시스템 정보 → 전원)
  • 화면 아래쪽 밝기 얼룩, 코팅 벗겨짐
  • 터치 바와 Touch ID가 잘 되는지

2017년 6월 출시

아이패드 프로 10.5

추천

120Hz ProMotion 화면을 처음 넣은 아이패드 프로예요. 화면이 부드럽고 애플 펜슬 1세대를 쓸 수 있어서, 필기와 PDF 읽기 기기로 아직 쓸 만해요.

칩
A10X Fusion
화면
10.5인치, 2224×1668, 최대 120Hz
펜·키보드
애플 펜슬 1세대, Smart Keyboard
단자
Lightning, 3.5mm 이어폰
잠금 해제
Touch ID (홈 버튼)
무게
약 469g (Wi-Fi 모델)

아직 좋은 점

  • 120Hz 화면이라 스크롤과 펜 반응이 지금 보급형 아이패드보다 부드러워요.
  • 스피커가 4개라 영상 볼 때 소리가 좋아요.
  • 이어폰 단자가 있어요.

알아 둘 점

  • 마지막으로 받을 수 있는 버전은 iPadOS 17이에요. iPadOS 18부터는 지원하지 않아서, 앱이 하나둘 설치되지 않을 수 있어요.
  • 애플 펜슬 1세대는 아이패드 Lightning 단자에 꽂아서 충전해요.
  • 무거운 앱을 여러 개 띄우면 느려져요.

중고로 살 때 확인할 것

  • 배터리 상태와 충전 단자가 헐겁지 않은지
  • 화면 모서리 들뜸, 멍(밝은 점)
  • Touch ID와 홈 버튼이 잘 되는지
  • 이전 주인의 Apple ID가 로그아웃됐는지

2019년 9월 출시

닌텐도 스위치 라이트

추천

들고 하는 데만 집중한 스위치예요. 가볍고 십자 버튼이 따로 있어서 2D 게임이나 이동 중에 하기 좋아요.

화면
5.5인치 LCD, 1280×720
저장 공간
32GB, microSD 카드로 늘릴 수 있음
배터리
약 3 ~ 7시간 (게임에 따라 다름)
무게
약 275g

아직 좋은 점

  • 스위치 게임 대부분을 그대로 할 수 있어요.
  • 가볍고 작아서 가방에 늘 넣고 다니기 좋아요.
  • 진짜 십자 버튼이 있어서 격투·플랫포머 게임에 편해요.

알아 둘 점

  • TV에 연결할 수 없어요. 들고 하는 모드만 돼요.
  • 컨트롤러가 본체에 붙어 있어서, Joy-Con을 떼서 하는 게임은 Joy-Con을 따로 연결해야 해요.
  • 스틱이 저절로 움직이는 쏠림이 생기면, 본체째 수리해야 해요.

중고로 살 때 확인할 것

  • 설정 → 컨트롤러와 센서 → 스틱 보정에서 손을 뗐을 때 가운데로 돌아오는지
  • 버튼이 눌린 채 걸리지 않는지
  • 이전 주인의 닌텐도 계정이 지워졌는지
